# Week 1 Assessment - Submission Branch

This repository contains my Python and Data Engineering Week 1 assessment work.

## Project Structure

- `data/` – Employee and department CSV files
- `notebooks/` – Jupyter notebook and Python export
- `reports/` – Charts created during the analysis
- `src/` – Python task programs

**Task 2 – Files and APIs**

- Handling API responses

**Task 3 – Data Analysis**
- NumPy array operations

- GroupBy and merge operations
- Creating charts with Matplotlib

**Task 4 – Git and Jupyter Notebook**
- Git repository and file management
- Working with terminal commands
- Employee data analysis using Jupyter Notebook
- Exporting the notebook as a Python file

## How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Create a virtual environment:

   `py -m venv .venv`

4. Activate it:

   `.venv\Scripts\Activate.ps1`

5. Install the required packages:

   `py -m pip install -r requirements.txt`
